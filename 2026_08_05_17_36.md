# RAVEN-M / AndroidWorld 下一阶段独立科学决策（2026-08-05）

## 1. Executive Verdict

**NO_GO_NEW_EXPERIMENT**

现有 AndroidWorld Hard 证据中，唯一同时具有自然发生、明确分母和较高频率的窄错误是：

> **控制器已经检测到 action loop / no-progress，并已发出恢复反馈，但该反馈没有约束下一步策略，agent 随即再次执行完全相同的动作。**

在 80 个动作接口受支持的 Hard cells 中，59 个至少连续重复同一动作 3 次，32 个至少连续重复 10 次；M0 共触发 46 次 loop critic，所有反馈均为 `reobserve`，44 次存在下一动作，其中 14 次立即重复原动作。这说明第一处可定位的断边是：

\[
\text{non-progress detection / critic feedback}
\;\not\Rightarrow\;
\text{next-action policy update}.
\]

该现象通过了**已有证据中的 prevalence screen**，也可以通过一个很小的 soft-feedback versus hard-binding intervention 区分多种解释。然而，它未通过 novelty gate：VLAA-GUI 已经以“相同动作未造成可见变化、重复屏幕状态或外部 loop judge”为触发条件，强制切换交互 modality、切换策略或 blacklist 原动作，并在闭环 GUI 任务中评估 task success、loop incidence 和 wasted steps；Plover、VeriGUI、BacktrackAgent 及现有 process audits 又覆盖了相邻的 post-action verification、stall detection、replanning 和 recovery。AndroidWorld、Qwen revision 或本仓库 controller 的变化只能形成 replication / engineering transfer，不能形成新的 causal contribution。

七项强制标准的结论如下：

| Required standard | 判定 | 理由 |
|---|---|---|
| 1. 自然错误有明确分母 | `PASS_FROZEN_REPORT_LEVEL` | 32/80 severe-loop cells；14/44 post-feedback immediate repeats。 |
| 2. 假设窄于一般模型弱点 | `PASS` | 目标边是 feedback signal → next-action update，不是泛化 grounding 或 planning。 |
| 3. 单一 intervention 可区分至少两个替代解释 | `PASS_IN_PRINCIPLE` | 固定 detector，仅改变反馈是否具有 action-admissibility 约束。 |
| 4. Closest prior 留下实质实验差异 | **`FAIL`** | VLAA-GUI 已覆盖相同 trigger、hard binding、闭环执行与行为/任务结局。 |
| 5. 强简单 baseline 与 resource matching | `PASS_IN_PRINCIPLE` | 可使用 soft feedback、neutral extra deliberation 与 hard exclusion 三臂。 |
| 6. 可冻结 qualification/effect/cost/stop gates | `PASS_IN_PRINCIPLE` | 但 novelty gate 先失败，后续门不得启动。 |
| 7. 正负结果均可解释 | `PASS_AS_REPLICATION_ONLY` | 结果可解释，但只构成 scaffold-specific replication，不构成新方向。 |

这些条件要求全部满足。第 4 项失败已经足够终止新实验；不应通过“换到 AndroidWorld”“换成 Qwen”或“做一个更干净的 ablation”把已有方法重新包装为新贡献。

## 3. Natural Failure Prevalence

### 3.1 Target error 的操作定义

本次唯一进入 screening 的自然错误定义为：

\[
E_{\text{nonbinding}}
=
\mathbf{1}
\left[
\begin{array}{l}
\text{controller 已检测到 loop / no-progress，}\\
\text{已向 policy 提供恢复反馈，且}\\
A_{t+1}=A_t
\end{array}
\right].
\]

这里的关键不是“agent 有时会循环”这一宽泛事实，而是：

> **已经存在 detector 和 feedback channel，但反馈未对下一动作形成行为约束。**

### 3.2 分子、分母与不确定性

下表中的区间是根据公开冻结计数计算的普通 95% Wilson intervals。它们仅用于描述该 frozen suite，不能被当作跨任务、跨模型或跨 benchmark 的 confirmatory intervals。

| 现象 | 分子 / 分母 | Annotation unit | 比例 | 95% Wilson interval | 是否进入 target prevalence |
|---|---:|---|---:|---:|---|
| 冻结 action interface 不支持任务要求 | 15 / 95 | cell | 15.79% | [9.81%, 24.43%] | 否；属于 protocol incompatibility |
| Supported-cell success | 1 / 80 | cell | 1.25% | [0.22%, 6.75%] | 仅作为 floor 背景 |
| 连续同一动作至少 3 次 | 59 / 80 | cell | 73.75% | [63.18%, 82.14%] | 宽 loop prevalence |
| 连续同一动作至少 10 次 | 32 / 80 | cell | 40.00% | [29.96%, 50.95%] | **severe-loop prevalence** |
| Loop feedback 后立即重复原动作 | 14 / 44 | loop event with next action | 31.82% | [20.00%, 46.56%] | **最直接的 non-binding prevalence** |
| 无 screenshot change 的 actions | 477 / 未公开总 action denominator | action | 不可计算 | 不可计算 | 不进入数值 gate |

这些分子分母来自冻结 forensic report：80 个 supported cells 中 59 个有三连重复，32 个有十连重复；46 次 M0 loop detections 中有 44 次可观察下一动作，其中 14 次下一动作完全相同。

### 3.3 是否足够频繁

**在该 frozen Hard suite 内，频率足以支持 mechanism screening。**

理由：

- severe loops 出现在 40% 的 supported cells；
- 其普通 Wilson lower bound 仍约为 30%；
- 在 detector 已经触发后的事件层面，31.8% 立即重复原动作；
- 现象不是根据一个单独失败 cell 发明的。

但存在三个重要限制：

1. 80 cells 来自 16 个 supported task instances × 5 variants，而不是 80 个相互独立任务；
2. 所有 Hard evidence 只有一个 seed；
3. 14/44 是嵌套在 19 个 M0 episodes 中的事件，不能按 44 个独立实验样本进行显著性推断。

因此，允许的结论是：

> 在该冻结 AndroidWorld Hard suite 中，repetitive non-progress 和 post-feedback immediate recurrence 都是高频工程失败。

不允许的结论是：

> 约 32% 的所有 AndroidWorld loop feedback 在总体分布上必然失效。

## 5. One Proposed Research Question

**授权的新研究问题：无。**

唯一通过自然 prevalence screening、但被 novelty gate 否决的问题是：

> 在已经确认同一 state–action pair 没有产生可见进展、且 loop detector 已触发的条件下，将 advisory feedback 从普通 `reobserve` 改成对下一步具有约束力的 exact-action exclusion，是否比 resource-matched soft feedback 更能降低 immediate recurrence 并恢复 task progress？

该问题具有清楚的 causal edge，也可以被小实验证伪；但它已经由直接 prior 覆盖，因而状态固定为：

```text
screened_candidate_id: CAND-NP-01
screened_candidate_status: REJECTED_BY_NOVELTY_GATE
authorized_hypothesis_id: NONE
```

不得把它改名为：

- feedback-grounded control；
- causal recovery binding；
- execution-policy commitment；
- controller-state alignment；
- non-progress-aware action gating；

然后作为新的研究贡献继续。

## 6. Causal Mechanism and Alternatives

### 6.1 First broken causal edge

候选机制的最小 causal chain 为：

\[
(S_t,A_t)
\rightarrow
O_{t+1}
\rightarrow
N_t
\rightarrow
L_t
\rightarrow
F_t
\rightarrow
A_{t+1},
\]

其中：

- \(S_t\)：当前 GUI state；
- \(A_t\)：已执行动作；
- \(O_{t+1}\)：动作后的 screenshot / state observation；
- \(N_t\)：no-progress 判定；
- \(L_t\)：loop detector 输出；
- \(F_t\)：critic feedback，例如 `reobserve`；
- \(A_{t+1}\)：下一动作。

现有自然证据表明：

- \(L_t\) 和 \(F_t\) 已经存在；
- 但 \(F_t\rightarrow A_{t+1}\) 不是 behaviorally binding；
- 14/44 次下一动作仍为完全相同的 \(A_t\)。

因此第一 broken edge 不是 detector acquisition，也不是 memory retrieval，而是：

\[
\boxed{\text{recovery feedback}\rightarrow\text{next-action admissibility / policy update}}
\]

### 6.2 最小可区分 intervention

从纯因果设计看，最小 intervention 应固定：

- 同一 task state；
- 同一已检测的 loop event；
- 同一 detector 输出；
- 同一 base model；
- 同一 history；
- 同一可用 token/call budget；

只改变下一动作是否允许重复：

| Conceptual condition | 反馈语义 |
|---|---|
| Soft feedback | 提供 `reobserve` / “try another approach”，但 action space 不变 |
| Resource-matched neutral control | 增加同等 call/token deliberation，但不给 recovery 指令 |
| Hard binding | 下一步禁止 exact repeated action；要求不同 target、action class 或 interaction modality |

两个概念 estimands 为：

\[
\Delta_R
=
P(R_{t+1}=1\mid do(B=1),L_t=1)
-
P(R_{t+1}=1\mid do(B=0),L_t=1),
\]

其中 \(R_{t+1}=1\) 表示立即 exact repeat，预期 \(\Delta_R<0\)；

以及：

\[
\Delta_Y
=
E[Y\mid do(B=1)]
-
E[Y\mid do(B=0)],
\]

其中 \(Y\) 必须是 native task success，而不能只用“重复动作减少”。

### 6.3 可区分的替代解释

| Alternative explanation | 若为真，概念 intervention 应出现的模式 |
|---|---|
| **A1：soft feedback 被 policy 忽略** | Hard binding 显著降低 immediate exact repeat，并提高首次有效 progress；neutral control 无同等效果。 |
| **A2：效果只来自额外 deliberation** | Neutral resource-matched control 与 hard binding 改善相近。 |
| **A3：detector 有 false positives，重复动作有时是必要 retry / wait** | Hard binding 虽减少重复，却降低 native success 或破坏 delayed progress。 |
| **A4：没有可行替代动作，根因仍是 grounding / workflow knowledge** | Exact repeat 降低，但转化为不同动作之间的 oscillation、其他 no-op 或 infeasible declaration；task success 不提高。 |
| **A5：screenshot no-change 漏掉 hidden-state progress** | Hard binding 在截图稳定但 native state 已变化的事件上造成伤害。 |
| **A6：动作字符串相同只是 canonicalization artifact** | 在语义 action、target、coordinates 和 state signature 重新核验后，所谓 repeat 不再成立。 |

该 intervention 确实能区分至少 A1、A2、A3 和 A4。然而，VLAA-GUI 已经实现了相同类别的 hard blacklisting / modality switch / strategy switch，Plover 也已使用 behavioral repetition 与 visual stability 联合触发 binding recovery。因此“实验可识别”不等于“实验值得作为新研究贡献执行”。
