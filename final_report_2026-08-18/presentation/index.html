A UNIFIED INTERPRETATION

综合全部实验：记忆能保存与复用已有能力，但未能单独补齐缺失能力

01

已经会做，但容易忘

对应机制 R2 verified / pending 账本

项目证据 6 / 19；相对 A1 1w / 0l，token / time 更低

02
复用已有经验

曾经成功，但不会稳定迁移

对应机制 AWM workflow memory

项目证据 24 个 slot 后仅 3 / 7 路线具备 donor coverage

03
生成缺失能力

从未形成可靠路线或核验

所需能力 规划、感知、恢复、grounding

项目证据 R2 失败中 7 题长期未解，6 题错误完成

决定性后续实验人工 / 强模型 expert donor + memory ON/OFF→成功：自生成 donor 是瓶颈｜仍失败：执行能力才是瓶颈

Related coordinates: AWM (workflow reuse), MemGUI-Bench (memory measurement). 本项目进一步追问记忆作用所需的能力基础。

这形成了可检验的研究命题：记忆收益取决于基础能力与经验覆盖，而 donor coverage 和最早断点应能预测哪类干预有效。

CONCLUSION

记忆能保存和复用能力，但未能单独补齐缺失能力

01

系统结果　R2 以最小 verified / pending 账本达到 6 / 19，在混合 Hard 任务上取得 31.6%，且零额外模型调用。

02

统一解释　R2 保存已有任务状态；AWM 复用已有成功经验；路线、感知和核验仍需要基础能力。

03

研究命题　P0 + L0-L6 将能力基础、donor coverage、事实断点和行为结果放入同一可验证框架。

不是“记忆越多越好”，而是已有能力能否被保存、复用，并真正改变动作。
