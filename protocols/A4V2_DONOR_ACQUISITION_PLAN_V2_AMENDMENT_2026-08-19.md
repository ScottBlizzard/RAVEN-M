# A4-v2 donor acquisition plan v2 amendment

Date: 2026-08-19
Experiment identity: `A4V2_FAITHFUL_OFFLINE_AWM_QWEN3VL32B_AW_HARD_S20260806_V1`

This prospective amendment is frozen before the first A4-v2 donor model call.
It changes donor acquisition coverage and prospectively narrows the OsmAnd
route classifier to an exact transferable prefix; the fixed seven, sampling,
native budgets, model, controller and stopping rules remain unchanged.
For execution, its Sports and OsmAnd rows supersede the corresponding two rows
of the 2026-08-18 preregistration table; the original text remains preserved as
the unexecuted draft record.

The unexecuted v1 plan listed `SportsTrackerActivitiesCountForWeek` as the
second required donor for the OpenTracks `retrieve_duration` route. Although
the preregistration permitted common navigation/read subroutines across those
classes, that row could conflict with the stricter exact-operation fidelity
rule. Plan v2 therefore uses `SportsTrackerActivityDuration` at two independent
seeds, `20260842` and `20260843`, both with the frozen native limit of 16.
The optional third OpenTracks slot is the same class at unused seed `20260844`
and may never be replaced by a count- or distance-operation donor.

No scored Hard trace, result, reward, donor response or model generation was
observed in making this correction. The original v1 content remains preserved
in Git history and in the readiness audit that identified the ambiguity.

The same prospective audit found that `OsmAndFavorite` cannot honestly induce
the final `Marker` operation. Plan v2 therefore labels the transferable route
as `open_location_result` and ends its claim at the visible Favorite/Marker
choice surface. The induced workflow must not recommend which final affordance
to choose. Scoring may retrieve this exact common navigation prefix for
`OsmAndMarker`; current pixels and the executor remain solely responsible for
the marker-specific final step.
The OsmAnd induction response is machine-gated: its final numbered step must
end with the exact stop sentence frozen in `a4v2_induction.py`, and response
text outside that receipt may not name Favorite/Marker/star/flag or a left or
right final option. A response that fails this boundary is induction-invalid;
it is never manually edited into the bank.

For this amendment, “exact operation-family compatibility” applies to the
induced reusable subroutine, not an unsupported claim that the donor completed
the entire scored objective. The OpenTracks donor subroutine is exact duration
reading; the OsmAnd donor subroutine is exact location-result navigation.

This is the only executable treatment revision for the V1 experiment family.
Every manifest, run signature, source lock, induction packet, preflight and
receipt must bind both this amendment file hash and the plan-v2 file hash. The
unamended draft is non-executable and has zero model calls.

Donor supplementation is also finite and prospective. All 14 required slots
run first. A route with fewer than two successes then runs its optional slot,
if any, followed by the single ordered final fallback frozen in plan v2. Every
selected supplement runs regardless of earlier supplement reward. After at
most four attempts per route, remaining coverage failure is sealed as
`DONOR_COVERAGE_BLOCKED`; seeds or task classes are not extended again under
this identity.

The paired-gain active control is deterministic before scoring: sort the seven
workflow IDs, cyclically derange their text content, and repeat/truncate source
words to the target workflow's exact whitespace-token count while retaining
the target route shell and wrapper. It receives a new ablation run identity,
its own bank hash, preflight and fresh receipt. Only tasks whose primary A4-v2
outcome is a paired gain over frozen A0 are run; the primary result determines
task inclusion but never changes the derangement algorithm or content.
